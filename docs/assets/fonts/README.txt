Fonts used by this site, served from here so visitors' browsers never contact Google.

Bricolage Grotesque, Atkinson Hyperlegible, Lexend, Barlow Condensed, IBM Plex Sans and IBM Plex Mono.

Files are the woff2 subsets (latin, latin-ext, vietnamese, cyrillic where available) published by Google Fonts.
Each page's @font-face rules are inline in its <style>; the browser only downloads the subsets a page needs.
